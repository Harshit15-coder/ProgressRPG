feat(map): add feature-flagged village/map view with decorative wandering characters

Adds a simple, purely-visual top-down map view showing a village's buildings
and characters, gated behind the map feature flag (testers only for now).

Backend:
- Fix place_characters.py:49 AttributeError (Building.Node.Kind.BUILDING ->
  Node.Kind.BUILDING) that broke seeding whenever populate_interiors hadn't
  run first
- Add locations/services/wander.py: decorative-only character movement
  within a village's boundary, deliberately independent of the
  Journey/pathfinding system used for real travel gameplay
- Add wander_tick Celery task (locations/tasks.py, scheduled in
  progress_rpg/celery.py) that nudges a random subgroup of idle characters
  each tick, indifferent to player-linking (purely visual, not gameplay)
- Add seed_village_view management command for seeding one small village
  without the interior/pathfinding/land-use pipeline the map view doesn't need
- Add core/migrations/0011_merge_20260709_2330.py: unrelated pre-existing
  migration conflict (two divergent core app migration leaves from separately
  merged branches) that blocked the web/celery containers from starting at all

Frontend:
- Add MapPage (frontend/src/pages/MapPage, route /map) rendering the map,
  independent of the not-yet-implemented player-character linking in
  fetch_info - resolves the population centre to show via
  GET /population-centres/ instead
- Rework Map.tsx: plot features directly in a viewBox derived from the
  GeoJSON bbox instead of a fixed-canvas pixel transform, so the map fills
  its (now square, aspect-ratio-driven) container and scales/zooms correctly;
  replace SVG <title> tooltips with the app-wide Radix Tooltip (shown
  instantly, scoped to the map); building tooltips show just the building
  type, not the full backend bookkeeping name; suppress the wander
  CSS transition during window resize/zoom to avoid a mid-resize
  disappear-and-slide-back-in glitch
- Add map feature flag (testers-only) gating the /map route

Tests: locations/tests.py (wander helper + task), Map.test.tsx (7 cases)

Related: files GH issue #538 for an unrelated MaintenanceWatcher/config.ts
false-positive "Server Unavailable" bug found while verifying this in-browser.
