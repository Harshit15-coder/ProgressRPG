Please read the [Code of Conduct](https://github.com/progressrpg/ProgressRPG/blob/main/CODE_OF_CONDUCT.md){target=_blank} before you start.

## Bug reports

Open an issue with a description of the problem, steps to reproduce it, and what you expected to happen.

## Feature requests

Check existing issues for duplicates, then open a new one if yours isn't there.

## Code contributions

- Base all branches and PRs on `development`, not `main`
- For anything beyond a small fix, open an issue first to discuss
- Keep PRs focused — one concern per PR
