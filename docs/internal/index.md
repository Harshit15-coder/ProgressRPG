# Internal Django Backend Documentation

This documentation is intended for maintainers working on the Django backend.

It covers:

- Application structure and ownership boundaries
- Key environment variables and runtime configuration
- A basic deployment runbook
- Non-obvious architectural decisions and tradeoffs

## Quick start (local docs)

Install docs dependencies:

```bash
pip install -r requirements-docs.txt
```

Serve docs locally:

```bash
mkdocs serve
```

Build static docs:

```bash
mkdocs build
```
